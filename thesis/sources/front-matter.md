# الصفحات التمهيدية

## الملخص

شهدت السنوات الأخيرة تزايداً حاداً في الهجمات السيبرانية المستهدفة لتطبيقات الويب والخدمات السحابية، مما فرض على المؤسسات والفرق التقنية إجراء فحوصات أمنية دورية باستخدام أدوات متخصصة مثل OWASP ZAP وnmap وffuf وغيرها. غير أن تشغيل هذه الأدوات يدوياً يُنتج مخرجات متفرقة وغير موحّدة، ويصعب إدارة صلاحيات الفحص والمصادقة على الأهداف المحمية، كما يتأخر تحويل النتائج إلى إجراءات عملية مثل التقارير الرسمية وتذاكر المتابعة في أنظمة إدارة المشاريع.

يهدف هذا المشروع إلى تصميم وتنفيذ **منصة ويب متكاملة لاختبار الأمن السيبراني** (New-Security-Scan / Cyber Security Testing Platform) تجمع بين واجهة أمامية حديثة مبنية بإطار Next.js 14، وواجهة برمجة تطبيقات خلفية (REST API) موثّقة بمواصفة OpenAPI 3.0.1. توفّر المنصة تنسيقاً موحّداً لإطلاق الفحوصات عبر سبع أدوات أمنية، وإدارة الأهداف والمصادقة، ونظام باقات يفرض حدود الرصيد ووقت التشغيل، وتكامل Jira لإنشاء التذاكر، ومساعد ذكاء اصطناعي لاقتراح إعدادات الفحص، ولوحة إدارة لمراقبة المستخدمين والطابور وسجلات التدقيق.

تم تحليل المتطلبات الوظيفية وغير الوظيفية، وتصميم الهندسة المعمارية بأسلوب BFF (Backend For Frontend)، وتنفيذ الواجهة الأمامية بالكامل مع اختبارات نهاية إلى نهاية (E2E) باستخدام Playwright. أثبتت النتائج قدرة المنصة على إدارة دورة حياة الفحص من التسجيل حتى التقرير، مع دعم التعدد اللغوي (العربية والإنجليزية) وآليات أمان متعددة الطبقات تشمل OTP وJWT وRBAC.

**الكلمات المفتاحية:** أمن سيبراني، اختبار الاختراق، OWASP ZAP، منصة SaaS، Next.js، OpenAPI، Jira، ذكاء اصطناعي.

## قائمة المصطلحات والاختصارات

| المصطلح | المعنى |
|---------|--------|
| API | واجهة برمجة التطبيقات (Application Programming Interface) |
| BFF | طبقة وسيطة بين الواجهة والخلفية (Backend For Frontend) |
| CVSS | نظام تقييم شدة الثغرات (Common Vulnerability Scoring System) |
| E2E | اختبار من طرف إلى طرف (End-to-End) |
| JWT | رمز وصول موقّع (JSON Web Token) |
| OTP | كلمة مرور لمرة واحدة (One-Time Password) |
| OWASP | مشروع أمان تطبيقات الويب المفتوح |
| RBAC | التحكم بالوصول المبني على الأدوار |
| REST | نمط معماري لواجهات الويب |
| SaaS | برمجيات كخدمة (Software as a Service) |
| VPS | خادم افتراضي خاص لتنفيذ الفحوصات |
| ZAP | أداة OWASP ZAP لفحص تطبيقات الويب |
