# الفصل الأول: المقدمة والإطار العام

## 1.1 خلفية البحث

أصبحت تطبيقات الويب والخدمات السحابية العمود الفقري للاقتصاد الرقمي، من التجارة الإلكترونية إلى الخدمات المصرفية والصحية والحكومية. مع هذا الانتشار، تزايدت سطحات الهجوم (Attack Surface) وباتت الثغرات البرمجية مصدراً رئيسياً لاختراق البيانات وتعطيل الخدمات. تشير تقارير OWASP وشركات الأمن السيبراني إلى أن غالبية الحوادث تنبع من ثغرات قابلة للاكتشاف مسبقاً عبر فحوصات منهجية.

تعتمد فرق الأمن والتطوير على مجموعة من أدوات الفحص المتخصصة: **OWASP ZAP** لفحص تطبيقات الويب وواجهات API، و**nmap** لاكتشاف الشبكات والخدمات، و**ffuf** لاكتشاف المسارات المخفية، و**wpscan** لمنصات WordPress، و**sqlmap** لاختبار حقن SQL، وأدوات مخصصة لـ XSS وشهادات SSL. كل أداة تُنتج تنسيقاً مختلفاً للنتائج، وتتطلب خبرة تقنية لإعدادها وتشغيلها وقراءة مخرجاتها.

ظهرت في السوق منصات سحابية (SaaS) لتوحيد هذه العمليات، إلا أن كثيراً منها إما مكلفة للفرق الصغيرة، أو لا تدعم التكامل مع أدوات إدارة المشاريع، أو تفتقر إلى حوكمة مرنة للاستخدام (Credits، حدود زمنية، قيود على الفحص المصدّق). من هنا جاءت الحاجة إلى منصة تجمع التنسيق والحوكمة والتكامل في حل واحد قابل للتوسع.

## 1.2 بيان المشكلة

يواجه المستخدمون والفرق التقنية عند إجراء فحوصات أمنية يدوياً المشكلات التالية:

1. **تشتت المخرجات:** كل أداة تُخرج تقارير بصيغ مختلفة (JSON، XML، نص خام)، مما يصعّب المقارنة والتحليل الموحّد.
2. **غياب الحوكمة:** لا توجد آلية مركزية لتحديد من يمكنه تشغيل أي أداة، ولأي مدة، وبأي عمق (light/deep/aggressive).
3. **صعوبة الفحص المصدّق:** تطبيقات الإنتاج غالباً تتطلب رموز JWT أو Cookies؛ إعداد ذلك لكل أداة على حدة مُرهق.
4. **تأخر الإجراءات:** تحويل الثغرات إلى تذاكر Jira أو تقارير PDF رسمية يتم يدوياً ويستغرق وقتاً طويلاً.
5. **غياب الرؤية التشغيلية:** لا يوجد طابور مركزي يُظهر موقع الفحص ووقت الانتهاء المتوقع (ETA).

## 1.3 أهداف المشروع

### الهدف العام

بناء منصة ويب متكاملة لتنسيق وإدارة فحوصات الأمن السيبراني، تربط بين واجهة مستخدم حديثة وواجهة برمجة تطبيقات خلفية قوية، مع دعم أدوات صناعية معيارية وتكاملات عملية.

### الأهداف الفرعية

| الرمز | الهدف |
|-------|-------|
| O-01 | تنفيذ نظام مصادقة آمن يعتمد OTP وJWT مع تجديد تلقائي للجلسة |
| O-02 | تمكين المستخدم من إدارة أهداف الفحص (URLs) وإعدادات المصادقة |
| O-03 | دعم سبع أدوات فحص مع إعدادات قابلة للتخصيص ومستويات عمق |
| O-04 | تطبيق نظام باقات يفرض الرصيد ووقت التشغيل وقيود الأدوات |
| O-05 | توفير تصدير تقارير PDF وتوليد تقارير ذكية بالذكاء الاصطناعي |
| O-06 | التكامل مع Jira عبر OAuth وإنشاء تذاكر من الثغرات |
| O-07 | توفير مساعد ذكي (Guided Setup) لاقتراح إعدادات الفحص |
| O-08 | بناء لوحة إدارة لإدارة المستخدمين والفحوصات والطابور والباقات |

## 1.4 أهمية المشروع

**الأهمية الأكاديمية:** يجمع المشروع بين مفاهيم أمن المعلومات (الثغرات، CVSS، OWASP) ومبادئ هندسة البرمجيات (معمارية طبقات، REST API، اختبار E2E، عقود OpenAPI)، مما يوفّر نموذجاً تطبيقياً لرسالة تخرج في هندسة البرمجيات أو أمن المعلومات.

**الأهمية العملية:** تُمكّن المنصة فرق التطوير وفرق الأمن من تشغيل فحوصات دورية دون الحاجة لخبرة عميقة بكل أداة، مع تحويل النتائج مباشرة إلى إجراءات (تذاكر، تقارير)، مما يُسرّع دورة إصلاح الثغرات.

## 1.5 نطاق المشروع

### ضمن النطاق

- تنفيذ الواجهة الأمامية الكاملة بإطار Next.js 14 (App Router).
- طبقة BFF Proxy لتوجيه الطلبات إلى الـ API الخلفي.
- تحليل وتوثيق الـ Backend من ملف OpenAPI (`data.json`).
- دعم لغتين: العربية والإنجليزية.
- اختبارات E2E بـ Playwright.
- تكامل Jira وStripe (عبر الـ API) والذكاء الاصطناعي (عبر الـ API).

### خارج النطاق

- كود المصدر للـ Backend (مبنيّ على .NET وفق بنية OpenAPI).
- البنية الداخلية لخوادم VPS المنفّذة للفحص.
- حل CAPTCHA تلقائياً (المنصة تعتمد جلسات مصدّقة بدلاً من ذلك).

## 1.6 منهجية العمل

اتُبعت منهجية تطوير البرمجيات التكرارية (Iterative):

1. **تحليل المتطلبات:** استخراج المتطلبات من مواصفة OpenAPI ومن تحليل كود الواجهة الأمامية.
2. **التصميم:** رسم المعمارية، نموذج البيانات، مخططات التسلسل وحالات الاستخدام.
3. **التنفيذ:** بناء صفحات Next.js، خدمات API، ومكونات واجهة المستخدم.
4. **الاختبار:** اختبارات E2E وتحقق من عقد الـ API.
5. **التوثيق:** إعداد الأطروحة والعرض التقديمي.

## 1.7 هيكل الأطروحة

تنقسم الأطروحة إلى تسعة فصول: المقدمة، الإطار النظري، تحليل المتطلبات، التصميم، تنفيذ الواجهة الأمامية، تنفيذ الخلفية، الاختبار، النتائج والمناقشة، والخاتمة، إضافة إلى المراجع والملاحق.
